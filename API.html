Esport-AHW — API Reference

PUBG & HOK broadcast backend · REST + Socket.IO · generated from server/src/routes

REST base
http://<host>:3000 — PORT, default 3000
Socket.IO
http://<host>:6060 — SOCKET_PORT, default 6060
Assets
STREAM_ASSET_BASE_URL — serves server/public/ statically
Auth header
x-api-key: <API_KEY>
Content type
application/json (body limit 50 MB) — except /upload-image (multipart)
Health
GET /health → { status: "ok", timestamp }
Auth rule — writes only. GET and HEAD are always open, on every route. POST/PUT/DELETE under /api and /upload-image require the x-api-key header; without it the server replies 401 {"error":"Unauthorized"}. Two write endpoints are deliberately exempt for machine ingest (curl/Postman/game dump): POST /api/stats/dump and POST /api/stats/dump-post-game. Overlay/stream routes carry no key at all — OBS browser sources cannot send headers.
